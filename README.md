# Convex Dart

Flutter/Dart packages for using [Convex](https://convex.dev) from Flutter apps.

## Workspace

This repository contains:

- [convex_dart](./convex_dart/) - Flutter runtime package
- [convex_dart_cli](./convex_dart_cli/) - code generator for Convex function specs
- [example](./example/readme.md) - working Flutter example and integration tests
